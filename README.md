# Cybersecurity & Ethical Hacking Practice Lab

## Overview

This project documents the design and implementation of a controlled
virtual laboratory for cybersecurity and ethical hacking practice.

## Lab Environment

- Kali Linux
- Oracle VirtualBox
- VirtualBox NAT Network
- Windows/Linux target machines
- VM snapshots
- Network connectivity testing

## Network Configuration

Network: 10.0.0.0/24

The laboratory uses a dedicated virtual NAT Network to allow
authorized communication between laboratory virtual machines.

## Objectives

- Configure a cybersecurity virtual laboratory
- Configure virtual networking
- Deploy Kali Linux
- Test communication between laboratory machines
- Practice ethical hacking in an authorized environment
- Document cybersecurity experiments

## Ethical Use

All security testing must be performed only against systems that
are owned by the learner or for which explicit authorization has
been provided.
